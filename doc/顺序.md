# 二、你目前最应该补的不是 RL，而是这 4 个缺口

## 第一优先级：运动学 + 动力学

下一步应该形成完整链路：

```text
关节角 q
   │
   ▼
正运动学 FK
   │
   ▼
足端位置 x
   │
   ▼
Jacobian J
   │
   ├─────────────┐
   ▼             ▼
足端速度       足端力
J q̇           F
   │             │
   └──────┬──────┘
          ▼
      关节力矩 τ
      τ = JᵀF
          │
          ▼
      电机执行
```

你至少要能够**不查资料解释清楚**：

### 1. FK

```text
q → x
```

关节角变化以后，足端在哪里？

---

### 2. Jacobian

```text
q̇ → ẋ
```

关节速度变化以后，足端速度是多少？

```text
ẋ = J(q)q̇
```

反过来：

```text
F → τ
```

足端受到一个力，需要每个关节输出多少力矩？

```text
τ = JᵀF
```

---

### 3. 动力学

你需要理解：

```text
M(q)q̈ + C(q,q̇)q̇ + G(q)
= τ + JᵀF_ext
```

以后面试官问：

> 为什么机器人站立时需要不同的关节力矩？

你不能只回答：

> 因为 PD 控制器。

而应该知道：

> 因为机器人受到重力，关节需要提供反重力力矩，实际力矩还受到惯性项、科氏力/离心力、接触力等影响。

# 三、第二优先级：把“控制”真正学成一条链

你现在会说：

> 我的 RL policy 输出关节目标位置，然后经过 PD 控制器。

但你需要真正理解：

```text
用户速度指令
      │
      ▼
   Policy
      │
      ▼
目标关节位置 q_des
      │
      ▼
     PD
      │
      ▼
目标力矩 τ
      │
      ▼
 电机驱动器
      │
      ▼
     电机
      │
      ▼
机器人运动
      │
      ▼
传感器反馈
      │
      └───────────────┐
                      ▼
                   下一时刻
```

典型 PD：

```text
τ = Kp(q_des - q)
  + Kd(q̇_des - q̇)
```

你需要能够回答：

### 为什么不用 PID？

因为机器人控制中：

```text
P → 纠正位置误差
D → 抑制速度、增加阻尼
I → 消除长期静态误差
```

但机械臂、腿式机器人中积分项容易：

* 积分饱和
* 接触状态变化导致累积错误
* 产生较大力矩
* 造成振荡

所以很多机器人使用：

```text
PD + 重力补偿
```

或者：

```text
PD + Feedforward
```

你之前问过的：

```text
τ = τ_PD + τ_ff
```

就属于这个体系。

# 四、第三优先级：状态估计

这个是很多只做 RL 的人容易忽视的地方。

机器人并不能直接知道：

```text
我现在的真实位置是多少？
我现在的速度是多少？
我身体是不是倾斜了？
```

它只能拿到：

```text
IMU
Joint Encoder
Contact Sensor
Camera
LiDAR
```

然后估计：

```text
真实状态
```

典型结构：

```text
IMU ──────────────┐
                  │
Joint Encoder ────┼──► EKF / State Estimator
                  │
Contact ──────────┘
                         │
                         ▼
                 base position
                 base velocity
                 orientation
```

你至少要掌握：

```text
IMU 加速度
    ↓ 积分
速度
    ↓ 积分
位置
```

为什么不能直接这么做？

因为：

```text
微小噪声
   ↓ 积分
速度误差
   ↓ 再积分
位置巨大漂移
```

所以需要：

```text
Prediction
+
Measurement Update
```

也就是 EKF 的核心思想。

目前很多腿式机器人岗位都会明确要求 IMU、编码器、接触信息融合，以及 EKF/UKF 等状态估计能力。([LinkedIn][2])
